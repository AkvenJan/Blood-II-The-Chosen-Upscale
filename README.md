# Blood-II-The-Chosen-Upscale
Upscale project for Blood II: The Chosen game and expansion pack The Nightmare Levels

Uses DTX v1.5 texture format

For starters I'll place all the original textures including converted from DTX format pcx and png images, alpha layers and used cluts. Everything you need to upscale textures and repack them back to DTX format

More info about DTX and its conversion can be found here:  
https://github.com/AkvenJan/DTX-Meta-Transfer  
https://www.moddb.com/mods/blood-ii-the-chosen-upscale-pack/tutorials/upscaling-lithtech-engine-games  
https://www.moddb.com/mods/blood-ii-the-chosen-upscale-pack/tutorials/upscaling-lithtech-10-engine-games  

Logic of folder structure:
 * Blood2 - original DTX (textures and skins), PCX (interface) and SPR (sprites) files for original game
 * Blood2 - converted PCX - all the DTX textures converted to PCX format using DEDIT editor
 * Blood2 - extracted alpha PNG - alpha layers were extracted from DTX files and converted to PNG
 * Blood2 - converted PNG - PCX were converted to PNG to use in any upscale process
 * Blood2 - extracted palettes ACT - palettes were exctracred in ACT and PNG clut formats from PCX files
 * Blood2 - old DTX to PNG - converted 4 DTX files with very old format with master palette applied. I suppose they aren't used in game
 * Blood2NM - original DTX (textures and skins), PCX (interface) and SPR (sprites) files for The Nightmare Levels
 * Blood2NM - converted PCX - all the DTX textures converted to PCX format using DEDIT editor for The Nightmare Levels
 * Blood2NM - extracted alpha PNG - alpha layers were extracted from DTX files and converted to PNG for The Nightmare Levels
 * Blood2NM - converted PNG - PCX were converted to PNG to use in any upscale process for The Nightmare Levels
 * Blood2NM - extracted palettes ACT - palettes were exctracred in ACT and PNG clut formats from PCX files for The Nightmare Levels
